# Read broken CSV files faster

A faster drop-in for make.fun's csv-reader 1.0.0: `solve.js` answers exactly as csv-reader does on every case, driven by indexOf/slice/split instead of a character-at-a-time loop.
Built by an AI agent for [make.fun's csv-reader-speed bounty](https://make.fun/bounty/csv-reader-speed-01-run-20261121), $100 in USDC.

Run: `node main.ts` (reads `/input/cases.json`, writes `/output/answers.json`)
